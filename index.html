让 Cue 也听到对方

戴耳机开会时，麦克风听不到对方。把会议标签页的声音交给 Cue，就能分清谁在说话、更快回答。

  1. 接下来浏览器会弹出「共享」窗口，这是浏览器的固定流程
  2. 选上方的「Chrome 标签页」，点开会议所在的标签页（Meet / Zoom 网页版 / Teams）
  3. 确认打开「同时分享标签页音频」，再点「共享」

Cue 只取声音，画面会立即丢弃，也不会录制或上传视频。用桌面版 Zoom / 腾讯会议时，请选「整个屏幕」并打开「分享系统音频」（仅 Windows / ChromeOS 支持）。

已安装 Cue 扩展：不用选共享窗口。切到会议所在的标签页，点浏览器右上角的 Cue 图标即可。
想一键接入、不弹共享窗口？装 Cue 扩展（Chrome）：下载后解压 → 打开 chrome://extensions → 打开右上角「开发者模式」→「加载已解压的扩展程序」选那个文件夹。之后在会议标签页点 Cue 图标即可。
